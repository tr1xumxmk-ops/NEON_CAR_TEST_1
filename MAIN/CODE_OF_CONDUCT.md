# Code of Conduct

SPARK CAR is a learning and engineering project. Contributors are expected to keep discussions respectful, constructive, and focused on the work.

Examples of helpful participation include clear bug reports, respectful technical disagreement, acknowledging others' work, and sharing reproducible tests. Harassment, personal attacks, discriminatory language, doxxing, and intentionally unsafe instructions are not acceptable.

Project maintainers may edit, close, or remove contributions that violate this standard. For sensitive concerns, contact the repository maintainer privately through the contact method listed on their GitHub profile.
